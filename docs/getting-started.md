# 体观康复 Skills｜完整使用手册

## 1. 你安装的是什么

当前安装包包含 7 个已发布 Skill：`/tiguan-rehab` 前门只在五条 Day-0 路径中做一次选择；评估课能力是附加的直接调用能力。

第一次使用不需要先有知识库、客户档案、标准经营表或系统接口。刚装好 WorkBuddy 时，当前对话就是临时工作台：一份资料、一段脱敏口述或几个能确认来源的数字，就足以开始一次真实体验。

1. `/tiguan-rehab`：最高需求、已有资料发现与任务路由；
2. `/tiguan-source-to-practice`：先讲理解，再对照资料纠偏并进入验证；
3. `/tiguan-practice-knowledge-base`：从当前结果开始的个人工作知识库；
4. `/tiguan-assessment-session-design`：问卷设置与答卷课前准备；
5. `/tiguan-service-ops`：单次服务记录草稿、客户回家说明与可选系统运营；
6. `/tiguan-post-session-questioning`：档案或事后口述驱动的多轮质询；
7. `/tiguan-business-review`：最小数据采集、三笔钱、三条经营线、剩课责任、现实产能与脱敏经营漏斗分析。

它们服务四个长期能力簇：实践认知校准、可验证服务设计、专业价值可见化、执业系统诊断。

## 2. 安装

WorkBuddy macOS：

前提：系统命令行可运行 `python3`；安装器会在写入前检查。

```bash
curl -fsSL https://raw.githubusercontent.com/Bbaozizz/tiguan-rehab-skills/main/tools/install-workbuddy.sh | bash
```

WorkBuddy Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/Bbaozizz/tiguan-rehab-skills/main/tools/install-workbuddy.ps1 | iex
```

其他支持 Agent Skills 的工具：

```bash
npx -y skills add Bbaozizz/tiguan-rehab-skills -g --all
```

安装后刷新或重启 Agent，输入：

```text
/tiguan-rehab 帮我找出现在最值得先解决的问题。
```

## 3. 让引导入口替你选择

你不需要先看七个 Skill 再猜哪一个适合。引导入口按两步问：

1. 如果这周只能改善一件事，你最希望哪件事发生变化？
2. 为了马上得到反馈，你已经有什么可以安全使用的材料？

如果需求或材料已经出现在当前对话、附件或用户明确点名的路径，Agent 会直接复用，不重复询问。随后它按“最高需求相关性 → 资料就绪度 → 最短反馈”只在五条路径中选一条，并在同一个任务中直接执行。

例如：你最想让买过的资料进入实践，手上也有一份课程笔记，引导入口会直接开始“资料变实践”。如果最高需求暂时缺一项关键材料，它会只说最小缺口；若第二高需求已有资料，也可以先用它得到第一次成功，但不会把最高需求悄悄替换。

“资料变实践”不会先生成总结。它会先让你讲出自己的理解，再把你的说法与资料逐项对照，找出最关键的一处理解一致、遗漏、误解或过度推断；你重新解释清楚后，才一起形成一个可验证的现实问题。

合成案例只能确认安装和路由能运行。真正有用的起点，是使用脱敏自有材料得到一份可复核反馈。

已经明确知道任务时，仍可直接调用对应 Skill。完整引导示例见 [`guided-first-run.md`](../skills/tiguan-rehab/examples/guided-first-run.md)。

例如已经明确要做评估课准备时，可直接上传自己的问卷完成一次设置；这是附加的直接调用能力。以后提交每位客户的脱敏问卷答案生成课前准备。PDF 是可选项，不是默认成功标准。

## 4. 没有现成系统时分别会发生什么

- **没有知识库**：先在当前对话完成任务；当结果值得复用时，知识库 Skill 再建立第一个最小条目。
- **没有客户档案**：口述一次脱敏服务过程，先生成专业记录草稿、客户回家说明和下次关注点；不会声称已经写入或发送。
- **没有质询档案**：用脱敏方式复述原计划和现场过程，内容标为事后新陈述，不冒充原始记录事实。
- **没有经营数据**：先回答数据记录在哪里，Skill 生成 7 天最小采集表并解释统计口径；七天后再分析，不凭感觉先给结论。

公开 Skill 不可能天生就拥有你的日历、记录、账务和消息系统权限。只有当工作区已配置官方适配器时，才能经过 `preview -> confirm -> apply -> readback` 真实执行。

没有适配器时，草稿与操作预览仍是可用结果，但不应声称已经安排、已经消课或已经发送。

## 5. 怎样审核输出

- 来源事实、用户/客户自述、专业人员判断、AI 推断和未知是否分开；
- 学习是否回到一个真实决策和验证动作；
- 知识库条目是否有来源指针和验证状态；
- 质询是否真的一次只问一个问题；
- 经营数据的分子、分母、时间窗口和未知是否清楚；
- 任何客户面向内容、临床决定和真实写入是否经过人的审核。

## 6. 隐私与专业边界

使用合成或脱敏材料。不提交客户数据库、联系方式、完整病历、可识别影像、原始对话、凭证或内部 ID。

AI 不诊断、不开处方、不决定动作/剂量/进阶，不自动发送客户消息。生成、测试和安装通过不等于真实临床、客户或经营结果。
