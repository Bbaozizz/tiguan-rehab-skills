# 运动健康独立服务经营模型

## 1. 三笔钱

| 字段 | 含义 | 不能误解为 |
| --- | --- | --- |
| `cash_collected` | 本期实际到账金额 | 本期利润 |
| `delivered_revenue` | 本期已经完成服务对应的收入 | 本期现金余额 |
| `prepaid_remaining_liability` | 已收款但仍待交付的服务责任 | 无条件客户资产 |

`cash_collected - delivered_revenue` 只表示本期现金与交付口径的差额。它不自动等于预收负债增量，因为本期也可能在交付以前周期收款的服务。

## 2. 七个经营驱动

```text
P = average_revenue_per_session       每次已完成服务的实际收入
v = variable_cost_per_session         每多完成一次服务增加的成本
F = fixed_operating_cost              每月固定经营成本
W = owner_target_wage                 老板目标工资
L = fixed_staff_cost                  除老板外的固定人工成本
R = reserve_target                    希望留下的经营余量
C = realistic_monthly_capacity        每月现实可售服务次数
u = planned_utilization_rate          计划现实利用率，0 到 1
```

挂牌价、体验价或最高课包价不能替代 `P`。存在赠课、退款、平台抽成或多种课包时，使用真实完成服务的加权实际收入。

## 3. 核心公式

```text
单次贡献 = P - v

场地不关门线所需次数 = ceil((F + L) / (P - v))
老板工资线所需次数   = ceil((F + L + W) / (P - v))
健康经营线所需次数   = ceil((F + L + W + R) / (P - v))

有效产能 = C × u
健康线产能缺口 = 有效产能 - 健康经营线所需次数

健康线所需活跃客户
= ceil(健康经营线所需次数 / 每位活跃客户月均实际服务次数)
```

只有 `P > v` 时模型才成立。缺任何一个驱动时，对应结果保持未知，不用 0 或行业均值补齐。

## 4. 三种经营形态怎样归类成本

| 形态 | 常见固定成本 | 常见单次变动成本 | 首要限制 |
| --- | --- | --- | --- |
| 自由教练 | 软件、保险、基础工具 | 按次场地、平台分成、耗材 | 场地价格与可用时段 |
| 单人门店 | 房租、水电、软件、设备折旧 | 单次耗材、支付手续费 | 老板时间与精力 |
| 小工作室 | 房租、软件、固定底薪、管理成本 | 教练课时费、耗材、平台抽成 | 团队产能、排班与交付一致性 |

同一成本在不同合同下可能归入不同类别。按“少完成一次服务时，这项成本是否立即减少”判断，而不是照抄表格。

## 5. 漏斗只负责定位断点

```text
被看见 → 有效咨询 → 预约 → 首次到店 → 购买阶段服务
→ 按计划完成 → 合理继续或结案 → 复购 / 转介绍
```

- 定位与营销主要影响被看见、理解和首次行动；
- 信任、产品入口、价格信息、回复和预约便利共同影响首次到店；
- 运营主要影响预约完成、记录、提醒和服务连续性；
- 专业判断与交付质量更直接影响阶段结果、合理继续和转介绍。

不要因为某一个比率低，就把原因直接归给最熟悉的能力。比率只告诉你“断在哪里”，真实原因仍需要经营者结合客户与现场事实判断。

## 6. 结果边界

这个模型属于管理会计和经营决策辅助，不是正式财务报表、税务申报、审计意见或当地合规建议。所有阈值、工资目标、余量和服务节奏都必须由经营者结合真实阶段确认。
