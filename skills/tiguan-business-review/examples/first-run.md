# 第一次｜没有经营表也能开始

以下为合成场景。仓库提供 7 天最小采集表 `../assets/minimum-7-day-collection.csv`，不要求先准备 JSON。

```text
/tiguan-business-review
我没有经营表，只知道最近生意不好。咨询在微信，预约在手机日历，上课和消课目前靠我自己记。
请先告诉我哪些能查、哪些要从今天开始记，再给我一份 7 天最小采集表和每个数字的口径。现在不要猜经营结论。
```

首次成功：用户当天就知道去哪里取数、每天记什么、七天后怎样回来分析；没有数据时不伪造当前优先级。有完整数据时再使用 `business-input.example.json` 和脚本复算指标。
