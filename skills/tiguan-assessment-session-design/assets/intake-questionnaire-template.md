# 课前信息收集（脱敏模板）

> 只收集设计本次评估所需的最小信息。真实使用时应由服务提供者按当地隐私与医疗规则处理原始信息。不要将可识别客户的原始回答直接交给第三方 AI。

1. 你最想改变的一件具体事是什么？
2. 它最容易在什么时间、地点、动作或工作/运动场景出现？
3. 它对工作、生活、睡眠、运动或情绪最大的影响是什么？
4. 这个情况在什么条件下会减轻或加重？
5. 你之前尝试过什么？当时和后续分别有什么变化？
6. 你目前认为问题可能是什么？这是经历、专业人员告知，还是你自己的猜测？
7. 这次评估结束时，哪个结果会让你觉得“这次值得”？
8. 有哪些已知的风险、医疗建议、近期变化或限制需要当面先说明？
