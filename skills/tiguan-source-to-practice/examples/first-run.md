# 第一次｜合成资料到实践

使用一段自己写的合成资料，不上传付费 PDF 原文：

```text
/tiguan-source-to-practice
这是一段合成学习笔记：“进行一次处理后，应尽量在相同条件下重复原先的功能任务，而不只看单一活动度。”
我当前的真实问题是：课后常记录动作范围，但忘了重测客户原来卡的任务。
不要先总结，也不要先告诉我怎么用。请先问我对这句话的理解，一次只问一个问题；等我回答后，再对照资料指出最关键的一处偏差。
```

首次成功：Agent 先让使用者解释，再明确一处理解一致、遗漏、误解或过度推断；使用者能重新讲清后，才形成一个由专业人员确认的现实验证问题。
