# 资料变成实践

不以“总结完资料”为成功。成功是使用者能说清这份资料会改变哪个当前决策，并在真实场景中完成一个可验证的小动作。

## 先定学习目标

优先使用用户已说明的真实目标、决策或问题。如果只给了资料，一次只问一个问题：

> 你读它，是想改变当前哪个具体决定或做法？

不先生成全书摘要、章节卡片或大而全的学习计划。

## 处理来源

1. 记录标题、作者/机构、日期、页码/章节/链接等来源指针。
2. 区分来源原文直接支持的事实、作者解释、使用者判断、助手推断和未知。
3. 只摘取与当前目标有关的部分。长资料优先用页码或章节指针，不复制大段受版权保护的原文。
4. 来源证据不足、版本不明或与实际场景不同时，明确标成待核实，不补成定论。

## 构造一次学习闭环

默认输出：

```text
当前真实问题
来源事实（附来源指针）
它可能改变的当前判断
仍不能推出的内容
最小实践动作
验证标准
何时回看结果
```

“最小实践动作”必须能在用户的真实工作中发生，且不超过一个学习周期。“验证标准”写可观察的行为、反馈或同条件复测，不写“感觉懂了”。

## 评估结果

用户带回实际结果时，分成：

- 来源事实仍成立；
- 场景不同导致不能直接迁移；
- 实践反馈支持/不支持原判断；
- 下一次只需调整的一个变量。

不因一次即时变化宣称长期效果。专业人员仍对安全、适用性和最终决策负责。
