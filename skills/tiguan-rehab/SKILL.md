# 体观康复 Skills 入口

只使用当前对话、附件和用户明确点名的路径或材料。不得扫描当前目录、工作区或未指明的历史资料；用户未提供的业务、临床和客户事实保持未知。

默认用户没有个人知识库、客户档案、标准经营表或系统适配器，不得把这些当作首次使用前提。用户现在能说出的一段经历、一次脱敏口述、一份附件或几个经营数字，都可以成为开始材料；文件系统和自动化只是后续增强。

目标不是介绍工具，而是发现一个最高需求，走一条路径，得到一个安全的第一份可复核输出。不得列出五条路径作为菜单，不得预排多 Skill 链。

## 只问最小问题

若当前对话已经足以判断最高需求与安全材料，直接路由。否则第一轮只问：

> 你现在最想先解决哪一个具体问题？如果这周只能改善一件事，你最希望哪件事发生变化？

回答后，只有仍缺少会阻止第一项安全行动的材料时，才再问一个材料问题：

> 为了现在就开始，你已经有什么**脱敏或可公开**的材料？没有文件也没关系，可以直接口述一段最近的真实情况。

一次只问一个问题。不要重复询问当前对话、附件或用户已明确命名的材料。

## 选择一条路径

按“最高需求相关性 → 已提供材料的安全性 → 最短可复核反馈”选择一条。判断由 Agent 完成，不使用关键词分类器。

| 需要发生的结果 | 选中路由 | 第一项可复核输出 |
| --- | --- | --- |
| 真正理解一份资料并用于当前问题 | `/tiguan-source-to-practice` | 先让用户讲出自己的理解，再对照资料找一个关键偏差 |
| 让 AI 下次能复用这次有价值的结果 | `/tiguan-practice-knowledge-base` | 从当前对话建立第一个含来源与验证状态的最小条目 |
| 一次服务结束后快速整理清楚 | `/tiguan-service-ops` | 没有档案也能从脱敏口述生成记录草稿、客户回家说明与未执行状态 |
| 深挖一次已完成服务的知行落差 | `/tiguan-post-session-questioning` | 没有档案时也可从脱敏复述开始，并一次只追一个问题 |
| 找一个经营数据断点 | `/tiguan-business-review` | 有数据就计算；没有数据就生成 7 天最小采集表与口径 |

`/tiguan-assessment-session-design` 是附加的直接调用能力：当用户明确要设置问卷或用脱敏答卷做课前准备时可直接使用；它不是 Day-0 五条主路径之一。

没有安全的已提供材料时，保留最高需求与最小未知；可在用户明确同意后只用对话中提供的合成 fixture 说明交互，不把它说成对真实工作的结果。

紧急医疗、诊断、处方、个体化动作、剂量、频率、排课或进阶决定不交给本公开包，由有资质专业人员负责。

## 紧凑交接并立即行动

内部按 [任务契约](references/task-contract.md) 填充六项；对用户只展示推进当前任务所需的简短部分。交接后在**同一对话**立即开始叶子 Skill 的第一项实质动作：不要要求用户再输入 slash 命令、复制背景或重新上传材料。

可用格式：

```text
最高需求：…
选中路由：…
现在开始：…
```

叶子完成当前任务后，只可返回 `/tiguan-rehab` 重新判断一个新的任务；不得从一个叶子直接跳到另一个叶子。

## 更新组合包

用户说“更新体观康复 Skills”时，根据当前 Agent 已公开的专用或通用安装命令更新本组合包；不修改用户生成的报告、案例、知识库或其他 Skills。

## 公共边界

- 使用脱敏材料、公开规则或明确提供的合成 fixture；不使用真实客户原文、身份信息、凭证或未指明路径。
- 区分来源事实、当事人判断、助手推断与未知。
- 静态检查、安装或文件生成只能证明相应技术动作，不等于真实业务、临床或服务结果。
