# WorkBuddy 引导式第一次使用

> 这是合成示例，用来检查入口是否会先找最高需求、再匹配已有材料，并在同一个任务里直接开始。

## 开始

用户安装并刷新 WorkBuddy 后，只输入：

```text
/tiguan-rehab 帮我找出现在最值得先解决的问题。
```

Agent 第一轮只问一个问题：

```text
你现在最想先解决哪一个具体问题？先不用想 Skill 名。
如果这周只能改善一件事，你最希望哪件事发生变化？
```

用户：

```text
我买了很多康复资料，但一直没有真正用进工作。
```

Agent 第二轮只盘点材料：

```text
为了让你马上得到反馈，你现在手上已经有什么可以用的材料？
```

用户：

```text
有一份自己买的肩痛课程笔记，可以先用其中一小节。
```

Agent 匹配后不让用户再输入另一个 Skill：

```text
你最在意的：让已经买过的资料真正进入下一次工作
你已经有的材料：一份肩痛课程笔记中的一小节
先走这条：资料变实践
为什么先走：它同时命中最高需求，而且现有材料今天就能产生反馈
现在就开始：请发这一小节，并告诉我下一次最可能遇到的真实决策；我会区分来源事实和待验证判断，只生成一个最小实践动作与验证标准。
```

接下来 Agent 立即按 `/tiguan-source-to-practice` 的规则继续，不要求用户重复目标。

## 没有最高需求所需资料时

如果用户最想改善经营，但还没有任何一个周期的分子、分母与时间窗口，Agent 先说清经营分析所缺的最小数据。若用户同时已有一份课程笔记，可以说明“资料变实践”是今天最快的第一次成功，并询问是否先用它跑一轮；经营问题仍保留为下一步，不能被悄悄替换。

合成案例跑通只证明安装、入口和路由可用。只有使用脱敏自有材料并带回可复核输出，才开始证明它对真实工作有用。
