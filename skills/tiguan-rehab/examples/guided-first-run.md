# WorkBuddy 引导式第一次使用

这是合成示例，展示 `/tiguan-rehab` 不展示路径菜单；第一轮只问一个最高需求问题，并在同一对话开始一项行动。

用户：

```text
/tiguan-rehab 我买了很多课程笔记，但一直没有用进工作。
```

Agent 只补一个最小材料问题：

```text
为了现在就开始，你已经有什么脱敏或可公开的材料？只说材料类型和与这个问题的关系即可。
```

用户：

```text
有一段公开指南的合成摘要，想影响下周的复盘判断。
```

Agent 不要求另一条 slash 命令，直接交接并开始：

```text
最高需求：让已有资料影响下一次复盘判断
选中路由：/tiguan-source-to-practice
现在开始：请指出摘要中能支持这个判断的一句来源事实；我会先列出它不能推出的内容，再形成一个非个体化的验证问题。
```

合成 fixture 只能验证交互边界，不能证明对真实工作有效，也不能产生个体化动作、剂量、频率、排课或临床处方。
