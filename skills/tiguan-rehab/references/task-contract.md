# 单路径任务契约

路由器在当前对话中为**唯一一条**选中路径建立下列六项；它是内部交接，不要求用户复制或填写模板。

```text
最高需求：用户此刻最想发生的可观察变化
安全的已提供材料：只列当前对话、附件或用户明确点名路径中的脱敏、公开或合成材料
最小未知：阻止第一项安全行动的唯一必要信息；没有则写“无”
选中路由：五条 Day-0 路径中的一条，或用户明确直接调用的附加能力
第一个可复核输出：本轮立刻可检查的草稿、事实分层、预览、追问或计算结果
硬边界：本任务不能做的事，例如不扫描未指明材料、不把未知写成零、不做诊断/处方/写入
```

若直接调用叶子 Skill 且没有上游契约，叶子只从当前对话的明确内容补出这六项中的最小必要部分。
